📌 1-1. 이 문서의 목적과 사용 방법

이 PRD(Product Requirements Document)는 Scope Manager MVP를 만드는 데 필요한 모든 기능 요구사항, 우선순위, 포함/제외 범위, 완료 기준 및 운영 정책을 통합 정의한다.

누가 이 문서를 사용하는가 — 현재 유일한 빌더인 Jey(PM 겸 기획자)가 Antigravity(AI IDE)에 프롬프트를 작성할 때 기준 문서로 활용한다. 기능 범위나 우선순위, 정책 결정이 필요할 때 이 문서로 돌아온다.

다른 기획 문서와의 관계 — 린캔버스(Why), 사용자 리서치(Who), 제품 비전(What & How)이 이미 완성되어 있으며, 이 PRD는 그 위에서 구체적으로 무엇을 어떤 순서로 만드는가를 정의한다.

⚠️ 섹션 2 — 전제 조건 및 제약사항

이 섹션은 시스템 설계의 근본 가정과 변경 불가능한 제약을 정의한다. Antigravity 빌드 프롬프트 작성 전 반드시 확인해야 하는 항목들이다.

✅ 2-1. 전제 조건 — Assumptions
  • 타겟 에이전시 PM은 기존 계약서·범위 정의 문서를 보유하고 있거나, 없는 경우 시스템 가이드를 통해 직접 작성한다
  • 계약서가 없는 경우(구두 계약 등) 시스템 진입 자체를 차단하고 "계약 범위 직접 작성 가이드" UI를 제공한다 — 프리랜서 특화는 P3로 연기
  • 클라이언트 추가 요청은 텍스트 또는 이미지(화면 캡처, 참고 이미지) 형태로 들어온다. 그 외 형태(구두, 파일, 링크 등)는 PM이 직접 텍스트로 요약해서 입력하는 것을 전제로 한다
  • PM은 판정 결과를 직접 클라이언트에게 전달하는 역할을 유지한다
  • 리포트의 전달 방식과 Scope Manager 도구 사용 여부 공개는 PM의 재량에 맡긴다
  • 시스템은 PM이 입력한 계약 범위 텍스트를 그대로 판정 기준으로 사용하며, 계약서의 법적 유효성이나 완결성은 검증하지 않는다
  • 클라이언트는 확인 링크를 통해 가입 없이 내용을 열람하고 동의 버튼을 누른다. 이 동의는 법적 구속력 있는 서명이 아닌 인지 확인 수준으로 정의한다
  • 계약 범위 확인(사전 동의)과 리포트 확인(사후 인지)은 목적이 다른 별개의 동의로 구분한다
  • 초기 사용자는 데스크톱 브라우저로 접속한다 (확인 링크 페이지는 모바일 대응 필수)
  • Supabase / Vercel / Claude API 서비스가 안정적으로 운영된다
  • MVP는 한국어 전용으로 시작한다 (다국어 불필요)
💡 사전 동의 vs 사후 인지 — 핵심 구분

계약 범위 확인 링크 (사전 동의) — 프로젝트 시작 전 클라이언트에게 발송. "이 범위로 계약합니다"에 대한 인지 확인. 타임스탬프 기록 목적.

리포트 확인 링크 (사후 인지) — 추가 요청 판정 후 발송. "이 요청은 범위 초과입니다"에 대한 인지 확인. 분쟁 대비 증거 기록 목적.

두 링크 모두 클라이언트 가입 불필요 (토큰 기반 UUID 접근), 법적 서명 아님.

F-02 워크스페이스 격리 & RLS 기반 데이터 보호 ⚠️ 보안 필수
사용자 스토리
에이전시 대표로서, 우리 회사의 계약서·판정 기록·손익 데이터가 다른 에이전시에게 절대 노출되지 않아야 한다. 고객 정보 유출은 비즈니스 리스크다.

  • /confirm-scope/[token] 및 /confirm/[token] 페이지는 RLS 예외 — 토큰 자체가 인증 수단이므로 별도 정책 적용

  • 계약서가 있는 경우에도 파싱 확정 후 클라이언트 범위 확인 링크 생성 선택 가능. "확인받으면 분쟁 시 더 강력한 근거가 됩니다" 안내 문구 표시
  • 범위 등록 완료 시 Claude API로 구조화 파싱 1회 실행 → 항목 리스트로 변환
  • 파싱 실패 또는 결과 빈약 시: "범위 항목을 자동으로 구성하지 못했습니다" 안내 + 수동 입력 모드 제공
  • 파싱된 항목 목록 PM이 확인·수정 가능한 미리보기 UI
  • 계약 범위 수정 시 버전 관리: 이전 버전 보존, 이전 판정 이력은 수정 전 버전 기준 유지. Fast Path 캐시 전체 자동 무효화
  • 범위 수정 후 기존 동의 기록 유지. 프로젝트 상단에 범위 수정됨 — 클라이언트 재확인 권장 경고 배지 (재확인 강제 아님)

  • 프로젝트 목록 페이지 — 최신순 정렬, 상태 필터
