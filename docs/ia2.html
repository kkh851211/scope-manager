IA 정보구조도 v1.0 Information Architecture MVP 단계
문서 개요
IA 정보구조도의 목적, 화면 분류 기준, 관련 문서와의 연결 구조를 정의합니다.
📌 이 문서의 목적과 사용 방법

IA(Information Architecture) 정보구조도는 Scope Manager의 전체 화면 목록, 화면 간 계층 구조, 각 화면의 URL과 역할을 정의하는 문서다.

누가 사용하는가 — Antigravity(AI IDE)로 Next.js 라우트와 페이지를 생성할 때, 특정 화면에 어떤 컴포넌트와 기능이 필요한지 확인할 때, 화면 간 이동 경로를 설계할 때 이 문서를 기준으로 삼는다.

다른 문서와의 차이 — PRD는 기능 요구사항, 유저 스토리는 사용 맥락, 기능 목록표는 버전 배치를 정의한다. 이 문서는 화면 구조와 라우팅을 정의한다.

IA 설계 원칙
"화면 구조는 유저 스토리 흐름을 따른다.
라우트는 기능 단위가 아니라 사용자 목적 단위로 나눈다."
PM이 "판정을 요청한다"는 목적으로 앱을 열었을 때, 최소한의 탭 이동과 클릭으로 목적을 완수할 수 있어야 한다. 화면 깊이(Depth)가 깊을수록 이탈 위험이 높아진다.

🚀 MVP 포함 화면 vs 이후 버전 화면
🚀 MVP v1.0 — 지금 바로 만드는 화면
  • 기준 — 핵심 가치 루프(가입→판정→리포트→PDF) 완성에 필수인 화면
  • S-01 ~ S-12 총 12개 화면
  • 인증(로그인·가입) / 온보딩 / 프로젝트 관리 / 판정·리포트 / 기본 설정
  • 데스크톱 퍼스트 — 모바일 반응형은 v2.0으로 이월
🔵 v1.1 — PMF 후 추가되는 화면
  • 기준 — Free → Starter 전환 가속에 필요한 화면
  • S-13 ~ S-17 총 5개 화면 추가
  • 홈 대시보드 / 손익 뷰 / 히스토리 타임라인 / 결제 관리
  • 진입 조건 — 첫 판정 완료율 >40% + 2주 재방문율 >30%
🟣 v2.0 — Pro 업셀 단계 화면
  • 기준 — Starter → Pro 전환 유인이 되는 화면
  • S-18 ~ S-22 총 5개 화면 추가
  • 팀원 관리 / 손익 분석 리포트 / 커스텀 규칙 / Pro 플랜 관리
  • 진입 조건 — Starter 30개 + Pro 업셀 문의 5건 이상
🚫 MVP에서 제외된 화면
  • 이메일 발송 화면 — Gmail로 수동 대체 가능 (v1.1)
  • 모바일 최적화 레이아웃 — 데스크톱 우선 (v2.0)
  • 팀원 초대·권한 관리 — 1인 사용 MVP 원칙 (v2.0)
  • API 문서 / 개발자 포털 — v2.0+ P3 단계

📖 이 탭을 읽는 법 — Antigravity 빌드 시 참조 순서

1단계 화면 ID 확인 → 2단계 URL 경로로 Next.js 파일 생성 → 3단계 주요 UI 컴포넌트 목록으로 shadcn/ui 컴포넌트 선정 → 4단계 진입/이탈 경로로 라우팅 로직 구현 → 5단계 연결 기능(F-xx)으로 API Route·Supabase 쿼리 연결
